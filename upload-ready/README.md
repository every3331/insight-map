# 洞见 · 跨学段错题地图

> 把一道错题，拆成可补的先后顺序。

洞见不是一个刷题网站。它把每次错误落到一张**跨学段知识图谱**（高中 32 节点 / 大学 44 节点）上，
用「前置关系 + 掌握度 + 证据数」算出一条从地基到断点的**最短补课链**，
再用三个 AI 助教角色——诊断、规划、阅卷——把这条链讲清楚、练扎实。

在线体验：`https://<你的用户名>.github.io/<仓库名>/`（静态版，AI 走内置引擎）
本地全功能：`node server.js` → <http://127.0.0.1:5173>

---

## 一、它解决什么问题

学生刷完题只知道"我错了"，不知道**错在哪一层**：

- 是这一步算错（符号／运算），还是这个概念没建立（概念混淆）？
- 这个概念的前置（比如"导数应用"之前的"导数定义"）是不是也虚着？
- 补的时候先补哪个、后补哪个？——顺序错了，越补越乱。

洞见把"错题"变成一张**可执行的补课清单**：每条错题落到图谱节点上，节点带掌握度与证据数（证据 2/2 才算掌握），
再由规划算法按拓扑序排出先修链。

## 二、核心功能

| 模块 | 能力 |
|---|---|
| **诊断** | 两段式：本地关键词召回 10 个候选 → 模型只在这 10 个里选 → schema 硬校验 → 三级降级 |
| **知识地图** | 9 条教材泳道星图 + 焦点节点图；节点四态（已掌握／待巩固／薄弱／断点） |
| **刷题** | 36 道精选题，待修复知识点优先出题；每题四段式解析（这题在问／怎么想到／一步步算／最容易错） |
| **试卷** | 8 套训练卷（2018–2025）共 168 题，五类题型；跨卷自由加题组卷；A4 打印（答案另页） |
| **错题本** | 按断点归档，待修复／已修复筛选，联动证据 |
| **规划助教** | 纯算法：断点集 → 前置闭包 → 拓扑排序 → 6 步补课链，每步带地图／看课／提问入口 |
| **阅卷助教** | 把标准解法拆成得分点，学生逐条勾选，分数自动算，再按 60%/40% 分流证据 |
| **教学** | 67/76 个节点配了已核实的 B 站视频（124 条），核不实的一律退回站内检索 |
| **番茄钟** | 1–180 分钟自定义，状态持久化 |

## 三、技术架构

```
┌──────────────────────────── 前端（零依赖静态应用） ────────────────────────────┐
│                                                                              │
│  index.html ──► app.js（路由 / 诊断 / 刷题 / 地图 / 错题本 / 教学）            │
│      │            │                                                          │
│      │            ├─ graph.js   76 节点 · 78 条前置关系 · 40 章节（单一真源）  │
│      │            ├─ data.js    变式 / 探针 / 题库 / 召回 / 本地诊断           │
│      │            ├─ papers*.js 8 套卷 168 题（UMD，浏览器与 Node 双端共用）    │
│      │            ├─ plot.js    自研函数绘图引擎（无第三方库）                 │
│      │            ├─ paper.js   试卷 / 组卷 / 评分点自评 / A4 打印             │
│      │            ├─ planner.js 补课路线算法（纯函数，可单测）                 │
│      │            └─ agent.js   三角色助教面板（上下文感知 + 三级降级）        │
│      │                                                                       │
│  localStorage：学习记录 / 试卷作答 / 助教历史（不上传、无账号）                │
└──────────────────────────────────────────────────────────────────────────────┘
                                    │  可选：POST /api/agent
                                    ▼
┌──────────────────── 后端（只做 AI 接入层，一个接口） ────────────────────────┐
│  A. 零依赖版  server.js + server/agent.js      （node server.js 即可跑）      │
│  B. 全栈版    web/app/api/agent/route.ts       （Next.js 15 + Vercel AI SDK） │
│                                                                              │
│  GET  /api/agent            健康检查（只回掩码，永不回明文 Key）              │
│  POST /api/agent            mode=diagnose 结构化诊断（nodeId 限制在候选内）    │
│                             mode=stream   流式讲解                            │
│                             mode=chat     多轮追问                            │
│  POST /api/agent/config     设置 Key（仅 127.0.0.1，落盘 .agent-config.json）  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**三级降级**（任何一环不可用都不断功能）：

```
真模型（有 Key）  →  本地引擎（无 Key / 无网络 / 请求失败）  →  纯静态（file:// 或 Pages）
```

## 四、安装与运行

### 方式 A · 双击就能看

直接用浏览器打开 `insight-map/index.html`。
除"接真模型"外全部可用（诊断走本地引擎，面板会标明来源）。

### 方式 B · 起服务（演示用这个）

```powershell
cd insight-map
node server.js            # 默认 5173；端口冲突可 $env:PORT="5174"; node server.js
```

打开 <http://127.0.0.1:5173>。零依赖，不需要 `npm install`。

### 方式 C · 接真模型（可选）

**C-1 零依赖后端**：在页面右下角「AI 助教 → 密钥」里填 Key（只发给本机后端，前端不保存），
或设置环境变量后重启：

```powershell
$env:AGENT_API_KEY  = "sk-..."                     # 任何 OpenAI 兼容网关
$env:AGENT_BASE_URL = "https://api.deepseek.com/v1"
$env:AGENT_MODEL    = "deepseek-chat"
node server.js
```

**C-2 Next.js 全栈后端**：

```powershell
cd web
copy .env.example .env.local     # 填 AGENT_API_KEY
npm install
npm run dev                      # http://127.0.0.1:3100
```

## 五、环境配置

| 变量 | 作用 | 默认 |
|---|---|---|
| `AGENT_API_KEY` | 模型网关 Key（**只在服务端**） | 空（走本地引擎） |
| `AGENT_BASE_URL` | OpenAI 兼容网关地址 | `https://api.deepseek.com/v1` |
| `AGENT_MODEL` | 模型名 | `deepseek-chat` |
| `PORT` | 零依赖后端端口 | `5173` |

模板：`web/.env.example`；依赖清单：`web/package.json`、`tools/domtest/package.json`（前端本体零依赖）。

## 七、隐私说明

- 无账号、无后端存储、无埋点：学习记录、试卷作答、助教历史全部存在**浏览器 localStorage**；
- 只有在你点击"诊断/追问"时，题干与你的写法才会发给你**自己配置**的模型网关；
- 换设备、清缓存即重置，页面内不提供任何数据上传入口；
- 题目与解析为项目自编（8 套卷按广东省考纲重构，非官方真题，卷内 `source` 字段已注明）。
