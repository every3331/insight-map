# 洞见 · 跨学段错题地图

> 错题本记录错误，知识地图记录「不会」。

**高中 → 大学**一条主线：函数性质 → 导数 → 极限 → 洛必达 / 定积分。初中内容按「已掌握」处理，不入图。

贴一道错题，先告诉你**答错没有、正确答案是什么、错在哪一步、怎么解**，**同时把这道题的函数图画出来**；再把这题**定位到知识地图上的一个断点**，顺着前置节点一路挖到地基。

> 他不是不会洛必达，他是从高中就没搞清导数是什么。

> **30 秒跑起来**：双击 `index.html`，或 `node server.js`。零依赖、不用 `npm install`。

## 如何运行

**环境**：Node.js 18+（只有跑后端才需要）。**零依赖，不用 `npm install`。**
前端是纯静态的 HTML/CSS/JS，双击就能跑。

### 方式 A · 双击就能看（评委最省事）

1. 双击 `index.html`
2. 浏览器打开，左上角徽标显示「离线演示」
3. 点示例「① 导数定义 · 大学」→ 点「诊断这道题」

不需要服务器、不需要联网、不需要任何配置。

### 方式 B · 起服务（演示和接模型用这个）

```powershell
cd insight-map
node server.js
```

终端会打印：

```
洞见 · 知识地图  →  http://127.0.0.1:5173
  模型：未配置 LLM_API_KEY（走本地兜底）
  缓存：3 条  (…\cache.json)
```

浏览器打开 `http://127.0.0.1:5173` 即可。

> macOS / Linux 一样，把 `cd` 换成你的路径，`node server.js` 不变。

### 可选 · 接真模型

```powershell
$env:LLM_API_KEY="sk-..."
$env:LLM_MODEL="gpt-4o-mini"
$env:LLM_BASE_URL="https://api.openai.com/v1"
node server.js
```

macOS / Linux 用 `export LLM_API_KEY=...`。
任何 OpenAI 兼容网关都行（DeepSeek、通义、vLLM、one-api），只换 `LLM_BASE_URL`。

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `5173` | 监听端口 |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | 网关地址 |
| `LLM_API_KEY` | 空 | **空 = 走本地兜底**，不报错 |
| `LLM_MODEL` | `gpt-4o-mini` | 模型名 |
| `LLM_TIMEOUT_MS` | `12000` | 超时后自动回落本地 |

### 30 秒验收

```powershell
node -e "fetch('http://127.0.0.1:5173/api/health').then(r=>r.json()).then(console.log)"
```

看到这个就通了：

```json

```

`hasKey:false` 是正常的 —— 说明没配 key，走的是本地兜底，功能一样能演示。

### 常见问题

| 现象 | 原因 / 解法 |
|---|---|
| `EADDRINUSE` | 端口被占：`$env:PORT="5174"; node server.js` |
| 徽标一直是「本地兜底」 | 没配 key，或网关不通；接口返回里的 `detail` 会写原因 |
| 断网了 | 不影响。缓存 + 本地引擎照跑，只是徽标变「本地兜底」 |
| 双击打开是空白 | 用 Chrome / Edge；内核太旧的浏览器不支持 |
| 图表显示不出来 | 地址加 `&fx=0` 关掉动效再试（低配机 / 录屏用） |

## 五个页面

| 页面 | 干什么 |
|---|---|
| **诊断** | 贴题 → 判对错 → 答案对照 → **函数图** → 为什么错 → 分步解析 → 定位 |
| **刷题** | 16 道高中 + 大学题，随机顺序，答错立刻给解析并把错题收进错题本 |

## 刷题

16 道题（导数运算 / 导数应用 / 极限 / 洛必达 / 导数定义 / 连续 / 指数对数 / 三角 / 求导法则 / 中值定理 / 不定积分 / 定积分 / 函数零点），随机打乱，答完一轮自动重开。

答完一题：
- 顶部 **答错了 / 答对了** + 命中知识点 + 错因
- **你选的 vs 正确答案** 并排
- 四步**解析**
- 有图的题直接出图（`f(x)=x·sinx` 会把 f′ 一起画出来）
- 答错自动写进**错题本**，右上角标「已加入错题本」

## 教学（一数 · B 站）

19 个知识点，每个对应 2 条一数视频入口：

- 左边是知识点清单（高/大标记），右边是该知识点的两张视频卡
- 卡片标签分「概念 / 题型 / 技巧 / 压轴 / 易错」，点「在 B 站打开」直达检索结果
- 右上角「一数 · B 站主页」

> 说明：**没有硬编码 BV 号**。那些号我无法核实，编出来就是死链。所有卡片打开的是 B 站站内检索（关键词固定含「一数」），既保证是一数的内容，也保证链接不会失效。

## 图像是跟着答案走的

图像不再是一个单独页面，**直接长在诊断结果里**，而且随答案变：

| 题 | 图上出现什么 |
|---|---|
| 导数定义（求 f(x)=x² 在 x=1 的导数） | 抛物线 + **x=1 处的切线**（琥珀虚线，标出 k=2） |
| 导数应用（求 x³−3x 的递增区间） | 蓝色 f(x) + **紫色虚线 f′** + 两个极值点绿点 |
| 洛必达（sinx/x） | 全区间曲线，一眼看出 x=0 处的高度是 1 |
| AI 出的题 | 每题自带一条曲线，全部标在图上 |

引擎还是 `plot.js`，零依赖：表达式解析（隐式乘法、`x²` 上标）、滚轮缩放、拖拽平移、悬停读数、f′ 数值导数、零点 / 极值 / 自定义标注点。

## AI 出题

没带错题也能演示：诊断页点「没有错题？让 AI 出一道 →」，从题库抽一道（6 道，覆盖导数运算 / 导数应用 / 极限 / 洛必达 / 导数定义 / 连续）。

选答案 → 提交 → **对错都走完整流程**：
- 选错：红条「答案不对」+ 你选的 vs 正确的 + **针对你选的这个选项**的错因 + 解析 + 对应的函数图
- 选对：绿条「答案正确」+ 这一步的关键 + 解析，图照样出

出完这一题同样可以「在知识地图中定位」。

## 3 分钟演示脚本

1. **0:00–0:20** 「我表弟大一，高数上挂了。他说洛必达、泰勒都背了，题还是不会做。」
2. **0:20–0:55** 贴一道题 → 诊断 → 「答案不对」+ 你的答案 / 正确答案并排 + **函数图和切线直接出来** + 为什么错 + 四步解析。
3. **0:55–1:20** 点「在知识地图中定位这个断点 →」→ 切地图，中心节点裂开，右侧栏弹出知识点信息。
4. **1:20–1:50** 「先探一句 →」→ 探针问的是**高中 5.1 导数概念**（标了「跨层」）→ 故意答错 → 高中节点也裂开，紫色虚线变红。
5. **1:50–2:20** 先补高中导数概念 → 答对 → 变绿；再回来补导数定义 → 变绿。
6. **2:20–2:40** 回「诊断」，点「让 AI 出一道」，故意选错，看错因和对应的图。
7. **2:40–3:00** 切「错题本」，几条记录都标着修复状态。

## 地图里的学习闭环

点任意节点，右侧栏按顺序展开五块：

1. **这个知识点是什么** —— 一句话定义 + 2 条要点 + 1 条「易错」
2. **前置节点** —— 标「跨层」，可以「先探一句」
3. **变式题** —— 同一知识点换场景
4. **答错立刻给解析** —— 分步解析 + 正确答案 + 「再试一次」，同时把介绍折成一行给解析腾位置
5. **「看这个知识点的一数视频 →」** —— 一键跳到「教学」页并选中同一个知识点

于是「我的极限被定位了」这件事，变成：**先知道极限是什么 → 再做一道 → 错了看解析 → 不会就去看视频**。

## 知识地图为什么更清楚了

- **砍掉初中**：19 个节点，两层（高中 9 / 大学 10），不再是一个学段挤一堆。
- **同心导引环**：内环 = 直接相关，外环 = 两跳，用虚线圈描出来，一眼看出远近。
- **焦点节点放大 + 泛光**，外环节点缩小、标签调暗，主次分明。
- **跨层边**画成紫色虚线，断点连线变红，学段的墙一眼能看见。
- **面包屑**：教材 › 章节 › 节点，点「回到断点」一键回中。

## 四个设计决定

### 1. 两段式召回，模型只在 10 个里选

```
第一段（本地）：关键词打分 → 召回 10 个候选节点
第二段（模型）：只把这 10 个喂进去 → 选 1 个 + 错因 + 置信度
```

服务端把 `nodeId` 硬性限定在候选集内，选到外面直接判失败、重试一次、再失败走本地。关键词支持 `#` 前缀表弱权重。

模型只输出 4 个字段，地图坐标、前置依赖、探针题、变式题、解析——一个都改不了。

```json
{ "nodeId": "der-def", "errorType": "概念混淆", "confidence": 0.79, "diagnosis": "一句话" }
```

### 2. 焦点图，不画全图

只画**当前节点 ±2 跳**，径向布局，`viewBox` 按包围盒动态裁切。19 个节点全画出来就是一坨线。

### 3. 前置探针

每个节点有 `prereq`。诊断命中后先问一句前置节点：答对 → 前置稳固；答错 → **前置节点也裂开**，地图上出现一条「洞的链条」。这是最有说服力的一拍。

### 4. 错因枚举按学段分开

| 学段 | 错因枚举 |
|---|---|
| 高中 | 符号错误 / 概念混淆 / 分类讨论不全 / 换元不当 / 运算跳步 |
| 大学 | 条件遗漏 / 定理误用 / 概念混淆 / 推演跳步 / 极限判错 |

高数最典型的错不是算错，是**没验证定理前提**。

## 任意题也能拿到结构化结果

不是只有三道示例题有解析。任意输入分两种情况：

| 情况 | 拿到什么 |
|---|---|
| 配了模型 key | 模型额外返回 `answer` / `steps[]` / `pitfall`，过三级校验后落盘 |
| 没配 key（离线） | 用该知识点的定义要点 + 易错兜底，结构一样、内容弱一档 |

所以「判定 → 图像 → 解析 → 常见错误 → 定位」这一屏，**任何题都能走完**。

## 巩固要两道题

答对一道变式题不会立刻愈合。第一次答对显示「还差一道」，再出一道同类题，第二道也对了才算补上 —— 掌握不是一次运气。

## 已知取舍

- **只做一条微积分主线**：19 个节点足够讲清「跨层」，再多 8 小时填不完。
- **初中整体当已掌握**：少一层，地图立刻清爽；跨层故事仍然成立（高中↔大学）。
- **出题是题库，不是模型生成**：现场不赌模型，16 道题的图都提前配好。
- **不上 KaTeX**：内容是「中文 + 行内数学」的纯文本，上 KaTeX 要重写 100+ 条字符串、加 300KB 字体，还得从 `file://` 跑通；改成自研轻量排版，收益接近、风险为零。
- **兜底比炫技重要**：三级兜底 + 录屏，比多接一个模型更能拿分。
