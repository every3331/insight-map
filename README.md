# 洞见 · 跨学段错题地图

**把一道错题，拆成可补的先后顺序。**

[![在线体验](https://img.shields.io/badge/在线体验-GitHub%20Pages-22D3EE?style=flat-square)](https://every3331.github.io/insight-map/)
[![License](https://img.shields.io/badge/License-MIT-0EA5E9?style=flat-square)](insight-map/LICENSE)
![零依赖](https://img.shields.io/badge/前端-零依赖-2DD4BF?style=flat-square)

> 洞见不是一个刷题网站。它把每次错误落到一张**跨学段知识图谱**（高中 32 节点 / 大学 44 节点）上，
> 用「前置关系 + 掌握度 + 证据数」算出一条从地基到断点的**最短补课链**，
> 再用三个 AI 助教角色——诊断、规划、阅卷——把这条链讲清楚、练扎实、判明白。

- 🌐 在线体验（静态版，AI 走内置引擎）：<https://every3331.github.io/insight-map/>
- 💻 代码仓库：<https://github.com/every3331/insight-map>
- 📄 技术文档：[说明/技术文档.html](说明/技术文档.html)（可用浏览器打印为 PDF）· [PDF 版](说明/洞见-技术文档.pdf)

## 一、项目介绍

### 1.1 问题

学生刷完题通常只知道"我错了"，却答不上三个问题：

| 问题 | 现状 |
|---|---|
| **错在哪一层？** | 是这一步算错（符号、运算），还是这个概念根本没建立？ |
| **先补哪一节？** | "导数应用"错了，根子可能在"导数定义"，甚至"一元二次不等式"；顺序错了越补越乱 |
| **凭什么算会了？** | 答对一次就算掌握？还是自评打个 8 分就算？ |

### 1.2 我们的答案

```
错题 → 诊断（错在哪一层）→ 定位（图谱上哪个节点）→ 规划（先补哪几节）
     → 练习（变式 + 试卷）→ 阅卷（按得分点自评）→ 证据（2/2 才算掌握）→ 回到诊断
```

核心原则：**规则负责约束，模型负责表达**。数学正确性由程序保证，模型只承担"读懂学生写法"与"把话说清楚"。

### 1.3 成果数据

| 维度 | 指标 |
|---|---|
| 知识图谱 | 76 节点（高中 32 / 大学 44）· 78 条前置关系 · 40 章节 · 5 条跨学段连接（无环且全可达） |
| 试卷 | 8 套（2018–2025）· 168 题（单选 80 / 多选 12 / 填空 24 / 判断 12 / 大题 40） |
| 题库总量 | 236 题（试卷 168 + 刷题 36 + 变式 12 + 探针 17 + 示例 3），全部带分步解析 |
| 大题解析 | 30 道双解法，每道附 1 条常见错解与错因 |
| 视频资源 | 67/76 节点、124 条已核实的 B 站视频（核不实的退回站内检索，零死链） |
| AI 角色 | 3 个（诊断 / 规划 / 阅卷），后端仅 1 个接口 `/api/agent` |
| 测试 | 20 项单元测试 + 41 项交互巡检 + 8 项静态托管断言 |

### 1.4 功能清单

| 模块 | 能力 |
|---|---|
| 诊断 | 两段式：本地关键词召回 10 个候选 → 模型只在这 10 个里选 → schema 硬校验 → 三级降级 |
| 知识地图 | 9 条教材泳道星图 + 焦点节点图；节点四态（已掌握 / 待巩固 / 薄弱 / 断点） |
| 刷题 | 36 道精选题，待修复知识点优先；每题四段式解析（这题在问 / 怎么想到 / 一步步算 / 最容易错） |
| 试卷 | 8 套卷 168 题，五类题型；跨卷自由加题组卷；A4 打印（答案另页） |
| 错题本 | 按断点归档，待修复 / 已修复筛选，导出 |
| 规划助教 | 纯算法：断点集 → 前置闭包 → 拓扑排序 → 6 步补课链，每步带地图 / 看课 / 提问 |
| 阅卷助教 | 标准解法拆成得分点，学生逐条勾选，分数由程序算，再按 60% / 40% 分流证据 |
| 教学 | 按节点组织的视频与资源 |
| 番茄钟 | 1–180 分钟自定义，状态持久化 |

## 二、技术架构

```
┌──────────────── 前端（零依赖静态应用，考察重点） ────────────────┐
│ index.html                                                      │
│   ├─ app.js      视图路由 / 诊断流程 / 刷题 / 地图 / 错题本      │
│   ├─ graph.js    76 节点 · 78 边 · 40 章（唯一数据真源，DAG）    │
│   ├─ data.js     变式 / 探针 / 题库 / 召回 v2 / 本地诊断         │
│   ├─ papers*.js  8 套卷 168 题（UMD：浏览器与 Node 单测共用）    │
│   ├─ paper.js    试卷 / 跨卷组卷 / 评分点自评 / A4 打印          │
│   ├─ planner.js  补课路线算法（纯函数）                          │
│   ├─ agent.js    三角色助教面板（上下文感知 + 降级）             │
│   ├─ plot.js     自研函数绘图引擎（无第三方库）                  │
│   └─ styles.css  极光青设计系统（23 个 CSS 变量）                │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 可选：POST /api/agent（唯一后端接口）
┌──────────────────────────▼──────────────────────────────────────┐
│ A. 零依赖后端  server.js + server/agent.js（node 直接运行）      │
│ B. 全栈后端    web/app/api/agent/route.ts（Next.js 15 + AI SDK） │
└──────────────────────────────────────────────────────────────────┘
```

**技术选型**：原生 HTML/CSS/JS 零构建（评审环境不可控，双击即用）· UMD 双端共用数据（浏览器与单测同一份）· 自研绘图引擎（不引图表库）· Next.js API Route 作为可选全栈形态。

**AI 集成（一个接口三种模式）**

| 模式 | 用途 | 输出 |
|---|---|---|
| `diagnose` | 诊断 | 结构化 JSON：$`nodeId` 必在候选集内，越界即判失败 |
| `stream` | 边讲边看 | 文本流，前端逐段写入 |
| `chat` | 多轮追问 | 文本流，携带最近 8 轮上下文 |

**三级降级**（评审现场友好）：

```
真模型（有 Key）→ 本地引擎（无 Key / 断网 / 请求失败）→ 纯静态（双击或 Pages）
```

## 三、安装运行指南

> **不需要安装任何东西**。三种方式任选其一。

### 方式 A · 一键启动（推荐）

双击根目录的 **`启动-洞见.bat`**：

| 你的电脑 | 脚本行为 |
|---|---|
| 装了 Node.js | 起本地服务 `http://127.0.0.1:5173` 并自动开浏览器（完整功能） |
| 没装 Node.js | 直接用浏览器打开 `insight-map/index.html`（除真模型外全部可用） |

### 方式 B · 直接双击网页

进入 `insight-map` 文件夹，双击 **`index.html`**。

### 方式 C · 在线体验

浏览器打开 <https://every3331.github.io/insight-map/>（静态托管，AI 自动降级）。

### 方式 D · 手动起服务（开发者）

```powershell
cd insight-map
node server.js            # 默认 5173；端口冲突可 $env:PORT="5174"; node server.js
# 打开 http://127.0.0.1:5173
```

### 可选 · 接真模型

**C-1 零依赖后端**：页面右下角「AI 助教 → 密钥」填入 Key（只发到本机后端，前端不保存），或设环境变量后重启：

```powershell
$env:AGENT_API_KEY  = "sk-..."                     # 任何 OpenAI 兼容网关
$env:AGENT_BASE_URL = "https://api.deepseek.com/v1"
$env:AGENT_MODEL    = "deepseek-chat"
node server.js
```

**C-2 Next.js 全栈后端**：

```powershell
cd web
copy .env.example .env.local     # 填 AGENT_API_KEY
npm install
npm run dev                      # http://127.0.0.1:3100
```

### 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `AGENT_API_KEY` | 模型网关 Key（**只在服务端**） | 空（走本地引擎） |
| `AGENT_BASE_URL` | OpenAI 兼容网关地址 | `https://api.deepseek.com/v1` |
| `AGENT_MODEL` | 模型名 | `deepseek-chat` |
| `PORT` | 零依赖后端端口 | `5173` |

> 模板：`web/.env.example`；前端本体**零依赖**，`web/` 与 `tools/domtest` 为可选开发依赖。

### 测试与验证

```powershell
cd insight-map
node test/run.js            # 单元测试：期望 20 passed, 0 failed

cd ..\tools\domtest
npm install                 # 首次
node run.js                 # 交互巡检：期望 全部通过（41 项）
node static-mode.js         # 静态托管模式：8 项
```

### 部署到 GitHub Pages（在线演示）

1. 仓库 **Settings → Pages**；
2. Source 选 `Deploy from a branch`，Branch 选 **`main`** + **`/ (root)`**；
3. 等 1–2 分钟，得到 `https://<用户名>.github.io/<仓库名>/`。

> 根目录需有 `index.html` 与 `.nojekyll`（已在仓库中）。

## 五、隐私与合规

- 无账号、无后端存储、无第三方埋点：学习记录、试卷作答、助教历史全部存在**浏览器 localStorage**；
- 只有用户主动点击"诊断 / 追问"时，题干与写法才会发送给其**自行配置**的模型网关；
- 换设备或清缓存即重置；页面内不提供任何数据上传入口；
- 题目与解析为项目自编：8 套卷按广东省考纲重构，**非官方真题**（数据文件 `source` 字段已注明）；
- B 站视频仅存储标题与链接，版权归原作者。
